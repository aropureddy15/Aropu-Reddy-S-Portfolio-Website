# Aropu Reddy S — Portfolio Website

## Files
- `index.html` — page content
- `style.css` — responsive styling
- `script.js` — mobile menu, current year, copy-email interaction
- `assets/profile.jpg` — your uploaded profile photo

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser.
3. Optional: use Visual Studio Code with the Live Server extension.

## Before publishing
Update the sample email (`your.email@example.com`) and LinkedIn/GitHub links in `index.html`.
Add your actual graduation branch/year. Check all project descriptions for accuracy.
This is a static portfolio; it does not include a backend or form submission service.

## Publish with GitHub Pages
1. Create a GitHub repository and upload all files, keeping the `assets` folder.
2. Open repository Settings → Pages.
3. Select the branch and root folder, then save.
4. Wait for GitHub Pages to provide your public URL.
